Filter, Then Aggregate

The endpoint can't group, but it can filter and it can drop columns. Push both into the query and the browser pulls less before it groups anything. The group-by still runs in the page, unchanged.

Pull less in two directions

Fewer rows · filter

OData on the Object endpoint. Text equality, in, date ranges, and, or and parentheses all work on 2026.Q2.
filter=region eq 'EMEA' and orderDate ge 2026-06-01
48,048 rows → 2,258

Fewer columns · fields

Ask only for the dimension and the measure the chart uses. The widget already does this.
fields=region,amount
One page of 500: 979 KB → 29 KB

Where it stops

A smaller questionA filter answers "EMEA in June", not "all regions". Questions over the whole Object get no help.
Still one pageThe browser still reads at most 500 rows per request. A filtered set past that is incomplete again.
Not in the widget yetThe fetch accepts filter and fields. There's no filter control in the config panel.
