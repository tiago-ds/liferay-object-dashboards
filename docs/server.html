Aggregating on the Server

object-aggregator is a Node Client Extension. It takes the same chart config as the widget, reads every page of the Object next to the portal, runs the same aggregate(), and sends back only the points. The client ships rows to the function; the server ships the function to the rows.

It reads as you

The service holds no credential of its own. It forwards the caller's token, so every page is read with that user's permissions. Reading as itself would let anyone chart rows they can't see.

Where it stops

Per-user cacheTwenty viewers pay for twenty scans. Correct permissions cost cache hits.
Scopes are staticOAuth2 scopes are declared per Object at build time, e.g. c_salesorder.everything.read. A new Object needs a redeploy.
Linear in rowsTen times the rows is ten times the scan. It stops reading at 100,000 rows and says so.
